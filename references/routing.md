# Routing

## Decision tree

1. If the user asks for a summary, select **summary**.
2. If the reader must understand a mechanism, select **technical** or
   **teaching**. Choose teaching when the reader is new to the domain.
3. If the reader must perform a task, select **procedure**.
4. If the reader needs a public argument or reflection, select
   **sophisticated prose**.
5. If the subject is sensitive and the reader needs context rather than
   instruction, select **compassionate**.
6. If the reader is one named person, select **letter**.
7. If the task makes a claim from a record, select **evidence brief**.
8. If the task seeks attention, activation, distribution, search visibility, or
   measurement, select **marketing**.

Then check the artifact and boundary. An office file needs structure
preservation. A protected record may yield a method but not its contents.
Local-only material stays unopened and undescribed.

## Summarization

Set the depth from the reader's decision:

| Reader needs | Keep |
| --- | --- |
| A quick orientation | Main claim and decisive context |
| A decision | Evidence, uncertainty, options, next action |
| A hand-off | Scope, decisions, open questions, owner |
| A research brief | Claims, sources, disagreements, limitations |

Extract what the source says before explaining what it means.

## Documentation

Before drafting, identify the product and version, the reader's question, the
authoritative source, and the example that proves the explanation. Cite the
source when the answer depends on documentation.

For a procedure, write the condition before the command. Keep one action per
step. State the risk after the action or warning.

## Existing DOCX, PDF, PPTX, and Markdown

Treat format as part of the source. Extract headings, tables, notes, links,
citations, named styles, list levels, page or slide order, and tracked changes
before rewriting prose. Preserve each unless the user asks to change it.
Inspect the final artifact in its native form.

## Marketing and DevRel

Marketing routes activate only for positioning, content, launch, acquisition,
conversion, distribution, search, or measurement.

1. Start with supplied customer language. Keep quotations separate from the
   interpretation.
2. Identify product truth, audience, problem, alternative, and one defensible
   message.
3. Use proof before persuasion. State what someone can now do.
4. Adapt the stable message to the channel after it is settled.
5. Define the metric and decision before reporting a result.

| Task | Required evidence |
| --- | --- |
| Positioning | Product truth, audience, alternative |
| Content strategy | Audience questions, expertise, search or distribution gap |
| Copy | Offer, proof, objection, desired action |
| SEO | Real query, useful source material, extractable facts |
| CRO | Observed friction, hypothesis, activation metric |
| Ads | Audience, angle, creative, spend boundary, measurement |
| Launch | Shipped artifact, warm-up, release, follow-through |
| Analytics | Event, funnel, attribution limit, decision |

Do not manufacture urgency, scarcity, consensus, fear, customer quotations, or
social proof.
